# ReactJS Props - Card Component

## Project Overview
This project demonstrates reusable React card components
using props and an array of objects.

## Features
- Reusable Card component
- Data passed using props
- Dynamic rendering using map()
- Gradient borders
- Responsive card layout
- Images, titles, and descriptions
- Hover animation

## Technologies Used
- ReactJS
- JavaScript
- CSS
- Vite

## How to Run

1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

   npm install

5. Start the project:

   npm run dev

6. Open the local URL displayed in the terminal.
